# GOV-AIOS Teach (Chrome extension)

Watches and highlights only; it never clicks, types or submits. It talks only to the panel at http://127.0.0.1:8765.

Extension ID (fixed by the `key` in manifest.json): `ngpmppfmaagibjeklnaldekaelgdeclh`

## Load
1. Chrome, `chrome://extensions`, turn on Developer mode.
2. Load unpacked, choose this `extension/` folder.

## Pair
1. In Studio, ask the panel to connect the extension and read the 6-digit code.
2. Click the extension icon, type the code, press Connect.
3. Sign in to the panel (type your code on Home), open the app's tab, press Teach.

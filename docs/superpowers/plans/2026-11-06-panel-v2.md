# Control panel v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After `sudo packaging/install.sh --no-claude` the panel runs at login on `http://127.0.0.1:8765/`, the admin signs in with a Touch ID button on the page, the panel survives locks, the audit is grouped app → runs → steps, and the spoken name is the laptop owner's.

**Architecture:** The panel server (`govaios/audit/web.py`) drops the single-use link and its self-shutdowns; browser sign-in becomes a page POST that triggers `auth.prove` with a 4-letter code shown on the page. A new `panel --agent` mode fixes the port, the apps folder (`<data home>/apps/flows`, pages in `<data home>/apps/pages`) and logging (`<data home>/panel.log`). Packaging adds a second LaunchAgent and seeds the apps folder.

**Tech Stack:** Python 3.14 stdlib, existing PyObjC auth, bash (install/uninstall), launchd, pytest.

**Spec:** `docs/superpowers/specs/2026-11-06-panel-v2-design.md` (builds on `docs/superpowers/specs/2026-11-06-control-panel-design.md` and `docs/superpowers/decisions/2026-11-06-control-panel-rulings.md`).

## Global Constraints

- Everything in the v1 plan's Global Constraints still binds (`docs/superpowers/plans/2026-11-06-control-panel.md`): `UI_PROFILE`, helper split before the sandbox, CSP `default-src 'none'; style-src 'unsafe-inline'`, no JavaScript, TOTP/session/ticket rules, exact refusal texts, no content in page/audit/stdout/log.
- Agent address exactly `http://127.0.0.1:8765/`; port 8765.
- Browser sign-in: Touch ID reason exactly `sign in to the GOV-AIOS panel, code {WORD}` where `{WORD}` is 4 random uppercase letters from `ABCDEFGHJKLMNPQRSTUVWXYZ`, shown on the signed-out page; one prompt at a time panel-wide (`"busy"`); 10 s panel-wide pause after a refused/cancelled prompt; sign-in lasts until any screen lock or 8 hours from sign-in.
- Pre-login CSRF: `pre` cookie (HttpOnly, SameSite=Strict, Max-Age 120) matching a hidden `pre` form field.
- The server never shuts itself down (not on lock, not on sign-in expiry). Lock → every browser signed out + v1 session end (`screen_lock`) and run stop.
- The 30-minute code session is one per panel, opened from Talk after sign-in; unchanged from v1.
- Apps folder: flows `<data home>/apps/flows/*.yaml`, pages `<data home>/apps/pages/` (siblings, as the engine expects). Install never overwrites; it lists `not updated: <relative path>` for files that differ from the repo.
- Name: default first word of the account's gecos full name (`pwd.getpwuid(os.getuid()).pw_gecos`), fallback `Admin`; override in `<data home>/panel.json` (0600, no-follow, atomic) key `name`; audit kind `setting` with field `field="name"` and no value.
- `panel.log`: lines only from the panel's own prints (steps, errors); rotate at 1 MB to `panel.log.1`; the same error line at most once per 60 s.
- LaunchAgent `com.govaios.panel`: `ProgramArguments` = app binary, `panel`, `--agent`; `RunAtLoad` true; `KeepAlive` `{SuccessfulExit: false}`; `ThrottleInterval` 30.
- Install end line exactly: `Control panel: http://127.0.0.1:8765/  (sign in with Touch ID on the page)`.
- All 583 existing tests keep passing (update only those this plan names).

## Review Focus

1. Another local process doing GET / then POST /signin in a loop: at most one prompt at a time, 10 s pause after each refusal, and its cookie is signed in only if the admin approves a prompt whose code it cannot show the admin. Test in Task 1.
2. Lock while two browsers are signed in and a run is live: both signed out, run stopped, server still answers. Test in Task 1.
3. Port 8765 already taken at agent start: exit code 1, one log line, no traceback spam on repeated starts within 60 s. Test in Task 4.
4. Install over an apps folder the admin edited: the edited file is untouched and listed as `not updated`. Test in Task 5.
5. A gecos with no full name, or a name with HTML characters: fallback `Admin`, page escapes it. Test in Task 3.
